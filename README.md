# Meu Caixa Nail

Sistema web simples de controle financeiro para uma profissional autônoma da área de nail design.

## Funcionalidades

- Login
- Dashboard financeiro mensal
- Cadastro de entradas
- Cadastro de gastos do negócio
- Cadastro de gastos pessoais
- Listagem, edição e exclusão de lançamentos
- Filtro por mês e ano
- Resumo mensal
- PWA para instalação no celular

## Tecnologias

- PHP
- MySQL
- Bootstrap 5
- JavaScript
- CSS
- PWA

## Como usar

1. Crie um banco de dados MySQL.
2. Importe o arquivo `database_exemplo.sql`.
3. Copie `config/conexao.exemplo.php` para `config/conexao.php`.
4. Preencha `config/conexao.php` com os dados reais do banco.
5. Acesse o sistema pelo navegador.

## Segurança

O arquivo `config/conexao.php` não deve ser enviado ao GitHub com dados reais de banco.
